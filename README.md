# Öğretmenim yıllık planlar

Öğretmenim uygulamasının indirdiği yıllık plan dosyaları.

- **Kaynak:** Millî Eğitim Bakanlığı tarafından öğretmenlerin kullanımına sunulan çerçeve/taslak yıllık planlar. Burada resmî yayın yerine geçmez; en güncel sürüm için MEB sayfalarına bakın.
- **Klasör düzeni:** `<eğitim yılı>/<ders>/<dosya>.xlsx`
- **Katalog:** `katalog.json`, uygulamanın okuduğu liste (kademe, sınıf, ders, dosya yolu). `belirsiz: true` olan kayıtlarda kademe/sınıf dosya adından anlaşılamadı.
- **Kaldırma:** Bir içeriğin kaldırılması gerekirse depo sahibine yazın, hemen kaldırılır.
